🌟 Overview

VibesDelas is a modern shopping and deals discovery platform built around an AI-powered experience.

The goal is simple:

«Make discovering useful products and great deals faster, smarter, and more enjoyable.»

VibesDelas combines a modern web interface with AI capabilities to create an engaging product-discovery experience for shoppers.

---

✨ Why VibesDelas?

Traditional shopping often means searching across multiple websites, comparing products, and trying to decide what is actually worth buying.

VibesDelas aims to simplify that experience by bringing product discovery + deals + AI together in a single modern interface.

🎯 Built for

- 🛒 Everyday shoppers
- 🔎 Deal hunters
- 💡 Product explorers
- 🤖 AI-powered shopping experiences
- 📱 Users who prefer a fast, modern interface

⚡ Getting Started

Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

---

1️⃣ Clone the repository

git clone https://github.com/vibesdealsai-gif/VibesDelas.git

2️⃣ Enter the project

cd VibesDelas

3️⃣ Install dependencies

npm install

4️⃣ Configure environment

Create your local environment file:

cp .env.example .env.local

Then configure the required environment variables.

«🔐 Never commit private API keys or secrets to GitHub.»

5️⃣ Start development

npm run dev

Open:

http://localhost:3000

---

🔐 Environment Variables

Environment variables should be stored locally in ".env.local".

Example:

# Add project-specific configuration here

# Example:
# API_KEY=your_api_key

Security best practices

- ❌ Don't commit ".env.local"
- ❌ Don't expose API keys in client-side code
- ✅ Use ".env.example" for documentation
- ✅ Configure production secrets through your hosting provider
